# Biruk Gizaw — Portfolio

A static fashion portfolio site for **Biruk Gizaw** (Fashion Designer & Tailor). Vanilla HTML, CSS, and JavaScript — no build step required.

## Local dev

```bash
npx serve .
```

The repo includes `serve.json` with `"cleanUrls": false` so links like `detail.html#id=1` are not 301-redirected (which can drop the outfit id on mobile). Restart `serve` after pulling changes.
